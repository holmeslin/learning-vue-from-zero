# Vue Router

到目前為止，你做的網頁只有一頁。但真正的網站有很多頁：首頁、商品列表、單一商品、會員專區。網址一變，畫面就換成對應的內容。

用 Vue 做這件事的時候，瀏覽器其實只載入了一次網頁，之後換頁都是 JavaScript 在背後把畫面換掉，而不是重新向伺服器要一份新的 HTML。這種網頁叫**單頁應用程式**（single-page application，簡稱 SPA）。讓網址和畫面對得起來的工具，就叫**路由**（router）。

Vue 本身只管畫面，換頁要靠另一個套件：**Vue Router**。它是 Vue 官方維護的路由函式庫，這本書用的是 Vue Router 5。

這一章會在你的專案裡，一步一步做出一個小型商品網站：

1. 安裝 Vue Router，設定第一個路由
2. 用 `RouterLink` 換頁
3. 共用版面與巢狀路由
4. 網址上的參數，例如 `/products/3`
5. 參數變了、元件卻沒重建的問題
6. 網址上的查詢參數，例如 `?category=mouse`
7. 用程式碼換頁
8. 導覽守衛：沒登入就擋下來
9. 找不到頁面時顯示 404
10. 延遲載入：用到哪一頁才下載哪一頁

## 準備環境

這一章接著用你在第 4 章用 create-vue 建立、第 8 章裝好 Pinia 的那個專案。後面的範例會整個取代 `src/App.vue`，所以如果裡面有想留下來的東西，先另外存一份。

如果你想從頭開一個新專案也可以（名字不要和原本的 `hello-vue` 重複）：

```bash
npm create vue@latest -- hello-router --pinia
cd hello-router
npm install
```

`--pinia` 會順便裝好第 8 章的 Pinia，第 8 集的導覽守衛會用到。

第二部會教 Nuxt，它的路由是用「檔案放在哪個資料夾」來決定的，寫法和這一章不一樣。Vue Router 5 其實也能這樣做（附錄一會介紹），但這一章一律手寫路由設定。先把「網址對應畫面」、「網址有參數」、「共用版面」這些觀念學會，之後換成哪一種寫法都很快能上手。
