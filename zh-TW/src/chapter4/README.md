# 第一個 Vue 程式

從這一章開始，終於要寫 Vue 了。

第 3 章最後一集你看過 Vue 的樣子：用模板描述「資料長這樣時，畫面該長怎樣」。這一章就是把那個模板學起來。你會學到怎麼建立 Vue 專案、元件是什麼、模板裡怎麼放資料、怎麼把資料傳給元件、怎麼依條件決定要不要顯示、怎麼把一串資料畫成清單，以及怎麼幫元件加樣式。

學完之後，你可以做出一個「靜態」的頁面：畫面長什麼樣子都由資料決定，但還不會對你的操作有反應。這一章的資料都是寫死的常數，要讓畫面跟著資料變動，是下一章響應式的工作。

## 準備環境

你需要：

- 已經安裝好 Node.js 和 VS Code（第 1 章）。Node.js 要 **24.15 或更新**的版本，在終端機輸入 `node -v` 確認；版本太舊的話，到 <https://nodejs.org/> 下載最新的 LTS 版重新安裝。
- 第 1 章建立的 `learning-vue` 資料夾。
- 懂基本的 JavaScript（第 1、2 章）和 HTML、CSS（第 3 章）。特別是三元運算子、`&&` / `||` / `!`、陣列和物件、`import` / `export`，這一章會一直用到。

第 1 集會在 `learning-vue` 裡用 create-vue 建立一個叫 `hello-vue` 的專案，並且在 VS Code 裝好 Vue 的擴充功能。**接下來幾章的練習都在這個專案裡做**，所以建好之後請好好保留它。之後需要 Vue Router、Pinia、Vitest 這些工具的章節，會再說明怎麼加裝或另外建專案；這一章用不到它們，建立專案時全部不選。

## 這一章的範例怎麼讀

每個範例的前面，都會用像 `src/App.vue` 這樣的寫法告訴你要把程式碼放進哪個檔案。檔案路徑是從專案資料夾 `hello-vue` 開始算的。範例通常是整個檔案的內容，直接整個換掉原本的內容就可以了。
