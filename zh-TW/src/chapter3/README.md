# HTML 與 CSS

Vue 最後畫出來的，還是 HTML 和 CSS 組成的網頁。所以在進入 Vue 之前，你得先認得這兩樣東西長什麼樣子。

這一章不會教完整的 HTML 和 CSS，那可以寫成好幾本書。我們只教**看得懂、寫得出簡單網頁**的程度，之後遇到新的標籤或樣式，再邊用邊查就好。

## 這一章的範例怎麼執行

前兩章用 Node.js 執行 JavaScript，這一章不需要。HTML 是給瀏覽器讀的，所以：

1. 在 `learning-vue` 資料夾裡，新增一個資料夾 `chapter3`，之後這一章的練習都放這裡。
2. 在裡面建立 `index.html`，貼上範例的內容，存檔。
3. 在檔案總管（Mac 是 Finder）裡找到這個檔案，**雙擊開啟**，瀏覽器就會顯示網頁。
4. 改了程式碼之後，存檔，再回到瀏覽器按重新整理（Windows 按 F5，Mac 按 ⌘R）就能看到變化。

每個範例都會寫出完整的檔案內容，你可以整段複製。有些範例會用到第二個檔案（例如 `style.css` 或最後一集的 `app.js`），要和 `index.html` 放在同一個資料夾。最後一集的 JavaScript 不是用 `node` 執行，而是由 `index.html` 載入，在瀏覽器裡跑。

## 這一章的順序

先學 HTML：結構、標籤、屬性、表單。再學 CSS：選擇器、盒模型、Flexbox。最後一集回頭看一個問題：為什麼只靠 JavaScript 做網頁會越寫越亂？這就是 Vue 要解決的事。
