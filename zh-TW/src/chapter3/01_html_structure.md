# HTML 結構

## 本集目標

寫出第一個 HTML 網頁，並且看懂標籤、元素和巢狀的意思。

## 正文

### 第一個網頁

在 `chapter3` 資料夾建立 `index.html`，貼上這些內容：

```html
<!DOCTYPE html>
<html lang="zh-TW">
  <head>
    <meta charset="UTF-8" />
    <title>我的第一個網頁</title>
  </head>
  <body>
    <h1>哈囉，世界！</h1>
    <p>這是我寫的第一個網頁。</p>
  </body>
</html>
```

存檔，雙擊開啟。瀏覽器的分頁標題會是「我的第一個網頁」，畫面上有一個大標題和一段文字。

### 標籤與元素

HTML 用**標籤**（tag）標示內容的意義。標籤用角括號包起來，大部分是成對的：

```html
<p>這是一段文字。</p>
```

- `<p>` 是**開始標籤**，表示「一個段落從這裡開始」。
- `</p>` 是**結束標籤**，比開始標籤多一個斜線。
- 中間是內容。

整個「開始標籤、內容、結束標籤」合起來叫一個**元素**（element）。

少數標籤沒有內容，不需要結束標籤，寫成一個就好，例如換行 `<br />` 或圖片 `<img />`。後面斜線只是習慣寫法，用來提醒「這個標籤自己就完整了」。

### 巢狀

元素裡面可以再放元素，就像盒子裡放盒子。這叫**巢狀**（nesting）：

```html
<ul>
  <li>蘋果</li>
  <li>香蕉</li>
</ul>
```

`<li>` 在 `<ul>` 裡面，我們說 `<ul>` 是 `<li>` 的**父元素**，`<li>` 是 `<ul>` 的**子元素**。縮排讓你一眼看出誰包著誰。每往裡面一層就縮兩格，VS Code 會幫你處理。

巢狀一定要「先開的後關」，不能交錯：

```html
<!-- 正確 -->
<p>這是<strong>重點</strong>文字</p>

<!-- 錯誤：標籤交錯了 -->
<p>這是<strong>重點</p></strong>
```

### 一個網頁的骨架

回頭看一開始的檔案，每一行都有用途：

- `<!DOCTYPE html>`：告訴瀏覽器「這是新版的 HTML」。每個網頁的第一行都是它。
- `<html lang="zh-TW">`：整個網頁的最外層元素。`lang="zh-TW"` 說明這個網頁是繁體中文，螢幕閱讀器和翻譯工具會參考它。
- `<head>`：放「關於這個網頁的資訊」，這些東西不會顯示在畫面上。
  - `<meta charset="UTF-8" />`：指定文字編碼。沒有它，中文可能會變成亂碼，所以每個網頁都要寫。
  - `<title>`：顯示在瀏覽器分頁上的標題。
- `<body>`：放**真正顯示在畫面上的內容**。

可以想成：`<head>` 是一本書的封面資訊，`<body>` 是內文。

### 註解

HTML 的註解寫法和 JavaScript 不同：

```html
<!-- 這是註解，瀏覽器會跳過它 -->
<p>這會顯示</p>
```

### 瀏覽器不在乎縮排和換行

HTML 對空白很寬容。連續多個空白或換行，瀏覽器都只當成一個空格：

```html
<p>
  這是     一段
  很多空白的文字
</p>
```

顯示出來是「這是 一段 很多空白的文字」，在同一行。想要換行，要用 `<br />` 或是拆成兩個 `<p>`。

### 出錯了也不會報錯

HTML 和 JavaScript 不一樣：寫錯了，瀏覽器不會跳出錯誤訊息，它會盡力猜你的意思。這讓除錯變難，因為畫面長得怪怪的，卻沒人告訴你為什麼。遇到這種情況，先檢查標籤有沒有成對、有沒有交錯。

## 重點整理

- HTML 用標籤標示內容，「開始標籤、內容、結束標籤」合起來是一個元素。
- 元素可以巢狀，標籤要先開的後關，不能交錯。
- 網頁骨架是 `<!DOCTYPE html>`、`<html>`、`<head>`、`<body>`；畫面上的內容放在 `<body>`。
- 瀏覽器不在乎縮排和多餘空白，也不會對錯誤的 HTML 報錯。
