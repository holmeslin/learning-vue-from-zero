# 常用標籤

## 本集目標

認識網頁上最常用的十來個標籤，知道什麼內容該用哪一個。

## 正文

HTML 的標籤有上百個，但日常用到的就這幾種。以下範例都放在 `<body>` 裡面，head 的部分和上一集一樣，不再重複。

### 標題與段落

```html
<h1>文章標題</h1>
<h2>第一節</h2>
<p>這是一段文字。</p>
<h2>第二節</h2>
<p>這是另一段文字。</p>
```

- `<h1>` 到 `<h6>` 是標題，數字越小越重要。一個頁面通常只有一個 `<h1>`。
- `<p>` 是段落。

選標題要看**意義**，不要看大小。想要字大一點，之後用 CSS 調整；標題層級是用來表示文章結構的。

### 強調

```html
<p>這是<strong>很重要</strong>的事，這個字<em>要加強語氣</em>。</p>
```

`<strong>` 表示重要（預設粗體），`<em>` 表示強調（預設斜體）。

### 連結

```html
<a href="https://www.wikipedia.org/">維基百科</a>
```

`<a>` 是連結，`href` 是要前往的網址。標籤中間的文字，就是畫面上可以點的字。

### 圖片

```html
<img src="cat.jpg" alt="一隻趴在窗邊的貓" />
```

`src` 是圖片的位置，`alt` 是這張圖的文字說明。圖片沒有載入時會顯示 `alt`，視障者的螢幕閱讀器也會唸它。**每張有意義的圖片都應該寫 `alt`。**

### 清單

沒有順序的清單用 `<ul>`，有順序的用 `<ol>`，每一項是 `<li>`：

```html
<ul>
  <li>蘋果</li>
  <li>香蕉</li>
</ul>

<ol>
  <li>打開瓶蓋</li>
  <li>倒入水</li>
</ol>
```

`<ul>` 的每一項前面是圓點，`<ol>` 的前面是 1、2、3。

### 按鈕

```html
<button>按我</button>
```

現在按了沒有任何反應，要搭配 JavaScript 才能讓它做事。

### 沒有意義的盒子：`div` 和 `span`

有時候你只是想把幾個東西包在一起，方便之後套樣式，但不想表達任何意義。這時用：

- `<div>`：**區塊**的盒子，自己獨佔一整行。
- `<span>`：**行內**的盒子，只佔它內容的寬度，不會換行。

```html
<div>
  <p>這個 <span>詞</span> 被包起來了。</p>
</div>
```

兩者看起來沒有任何樣子，是專門留給 CSS 用的。區塊和行內的差別，是 HTML 的一個基本概念：`<p>`、`<h1>`、`<ul>`、`<div>` 都是區塊；`<a>`、`<strong>`、`<span>`、`<img>` 都是行內。

### 有語意的區塊

如果盒子有明確的角色，就選有名字的標籤，而不是一律用 `<div>`：

```html
<header>網站標題與選單</header>
<nav>導覽連結</nav>
<main>主要內容</main>
<footer>頁尾版權資訊</footer>
```

它們外觀上和 `<div>` 一樣，但告訴瀏覽器、搜尋引擎和螢幕閱讀器「這一塊是什麼」。能用有語意的標籤就用，這是讓網頁更好用的小習慣。

### 一個完整的小頁面

```html
<!DOCTYPE html>
<html lang="zh-TW">
  <head>
    <meta charset="UTF-8" />
    <title>水果介紹</title>
  </head>
  <body>
    <header>
      <h1>水果介紹</h1>
    </header>
    <main>
      <h2>今天的水果</h2>
      <ul>
        <li><strong>蘋果</strong>：脆甜</li>
        <li><strong>香蕉</strong>：軟綿</li>
      </ul>
      <p>更多資訊請看<a href="https://www.wikipedia.org/">維基百科</a>。</p>
    </main>
    <footer>
      <p>製作：我自己</p>
    </footer>
  </body>
</html>
```

試著存成 `index.html` 並開啟，再改一些文字、多加幾個清單項目，看看畫面怎麼變。

## 重點整理

- `<h1>`～`<h6>` 是標題，`<p>` 是段落，`<strong>` 和 `<em>` 表示重要和強調。
- `<a href>` 是連結，`<img src alt>` 是圖片，`alt` 一定要寫。
- `<ul>` 和 `<ol>` 搭配 `<li>` 做清單，`<button>` 是按鈕。
- `<div>` 和 `<span>` 是沒有意義的盒子，前者是區塊、後者是行內。
- 盒子有明確角色時，優先用 `<header>`、`<nav>`、`<main>`、`<footer>` 這類有語意的標籤。
