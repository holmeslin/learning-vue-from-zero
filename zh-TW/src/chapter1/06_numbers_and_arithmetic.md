# 數字與算術

## 本集目標

用 JavaScript 做加減乘除，並且知道運算的先後順序。

## 正文

### 數字不用引號

數字直接寫，不用引號：

```js
const price = 120;
const quantity = 3;
console.log(price * quantity);
```

執行結果：

```text
360
```

`*` 是乘號。鍵盤上沒有 × 這個符號，所以程式語言都用 `*`。

### 五種基本運算

| 運算子 | 意思 | 例子 | 結果 |
| --- | --- | --- | --- |
| `+` | 加 | `7 + 2` | `9` |
| `-` | 減 | `7 - 2` | `5` |
| `*` | 乘 | `7 * 2` | `14` |
| `/` | 除 | `7 / 2` | `3.5` |
| `%` | 取餘數 | `7 % 2` | `1` |

`%` 是「除完剩下多少」。`7 % 2` 是 1，因為 7 除以 2 商 3 餘 1。它最常見的用途是判斷奇偶數：一個數 `% 2` 等於 0 就是偶數。

```js
console.log(7 + 2);
console.log(7 - 2);
console.log(7 * 2);
console.log(7 / 2);
console.log(7 % 2);
```

```text
9
5
14
3.5
1
```

### 先乘除後加減

和數學課一樣，乘除比加減先算，有括號就先算括號：

```js
console.log(2 + 3 * 4);
console.log((2 + 3) * 4);
```

```text
14
20
```

不確定順序的時候，直接加括號。多一組括號不會錯，少一組可能就錯了。

### 讓變數自己加

程式裡很常需要「把某個數字加上去」：

```js
let count = 0;
count = count + 1;
console.log(count);
```

```text
1
```

`count = count + 1` 的意思是「把 `count` 現在的值加 1，再放回 `count`」。這太常用了，所以有縮寫：

```js
let count = 0;
count += 1;
console.log(count);
```

`count += 1` 和 `count = count + 1` 完全一樣。`-=`、`*=`、`/=` 也都有。

### 小數的小陷阱

試試看這個：

```js
console.log(0.1 + 0.2);
```

```text
0.30000000000000004
```

這不是 JavaScript 的 bug，幾乎所有程式語言都這樣，原因是電腦存小數的方式天生有誤差。現在只要記得：**小數運算的結果可能會差一點點**。需要顯示給人看的時候，可以用 `toFixed` 指定小數位數：

```js
const total = 0.1 + 0.2;
console.log(total.toFixed(2));
```

```text
0.30
```

## 重點整理

- 數字不加引號，`+`、`-`、`*`、`/`、`%` 做加減乘除和取餘數。
- 先乘除後加減，不確定就加括號。
- `count += 1` 是 `count = count + 1` 的縮寫。
- 小數運算會有微小誤差，顯示時用 `toFixed` 整理。
