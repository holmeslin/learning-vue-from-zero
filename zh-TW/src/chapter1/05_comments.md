# 註解

## 本集目標

在程式碼裡寫給人看的說明文字，而且不影響程式執行。

## 正文

程式碼是給電腦執行的，但也是給人讀的，包括三個月後的你自己。**註解**（comment）就是寫在程式碼裡、電腦會直接跳過、專門給人看的文字。

### 單行註解

`//` 後面到行尾的東西都是註解：

```js
// 這一行是註解，不會被執行
console.log("哈囉"); // 這也是註解，寫在程式碼後面
```

執行結果只有一行：

```text
哈囉
```

### 多行註解

要寫很多行時，用 `/*` 開頭、`*/` 結尾：

```js
/*
  這裡面全部都是註解，
  可以寫好幾行。
*/
console.log("哈囉");
```

### 註解該寫什麼

好的註解說明「為什麼」，而不是「做什麼」。程式碼本身已經在說做什麼了。

不好的註解，只是重複程式碼已經說的事：

```js
const maxUsers = 100; // 把 maxUsers 設成 100
```

好的註解，說明程式碼看不出來的理由：

```js
const maxUsers = 100; // 伺服器一次最多撐 100 人
```

### 暫時關掉程式碼

註解還有一個常見用法：想暫時不執行某一行，但又不想刪掉，就把它變成註解。

```js
console.log("這行會執行");
// console.log("這行先不執行");
```

VS Code 有快捷鍵：游標放在那一行，Windows 按 Ctrl+/，Mac 按 ⌘/，就能把那一行變成註解或還原。

## 重點整理

- `//` 是單行註解，`/* */` 是多行註解。
- 註解是給人看的，電腦會跳過。
- 註解寫「為什麼這樣做」，不要重複程式碼已經表達的事。
- 把程式碼變成註解可以暫時關掉它，快捷鍵是 Ctrl+/ 或 ⌘/。
