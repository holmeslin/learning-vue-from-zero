# 安裝 Node.js 與 VS Code

## 本集目標

裝好 Node.js 和 VS Code，建立一個放練習檔案的資料夾，並且學會打開終端機。

## 正文

你需要兩個工具：

- **Node.js**：用來執行 JavaScript。
- **VS Code**：用來寫程式碼的編輯器。你也可以用其他編輯器，但這本書的說明都以 VS Code 為準。

兩個都是免費的，Windows 和 Mac 都能裝。

### 安裝 Node.js

1. 打開 <https://nodejs.org/>。
2. 下載標示 **LTS** 的版本。LTS 是「長期支援」的意思，是最穩定的版本。這本書是用 24 版寫的，請確認版本是 24.15 或更新，後面用到的工具（例如第二部的 Nuxt）要求至少這個版本。
3. 執行下載的安裝檔，一路按「下一步」用預設選項裝完就好。

安裝 Node.js 時會一起裝好 **npm**，它是用來下載別人寫好的套件（package）的工具，第 4 章開始會常用到。

### 安裝 VS Code

1. 打開 <https://code.visualstudio.com/>。
2. 下載並安裝。一樣用預設選項就好。

### 建立練習用的資料夾

在你方便找到的地方（例如桌面或「文件」）建一個資料夾，取名 `learning-vue`。這本書所有的練習檔案都放在這裡。

打開 VS Code，從上方選單選「檔案」→「開啟資料夾」，選剛才建立的 `learning-vue`。左邊會出現這個資料夾的檔案清單，現在還是空的。

> VS Code 的介面預設是英文。如果想改成中文，可以裝「Chinese (Traditional) Language Pack」這個擴充功能。這本書的說明會用中文的選單名稱，英文介面對應的位置是一樣的。

### 打開終端機

終端機（terminal）是一個用打字下指令的視窗。接下來執行程式都靠它。

VS Code 內建終端機，從上方選單選「檢視」→「終端機」就會在下方打開。打開後會看到一行文字和一個閃爍的游標，那就是等你輸入指令的地方。

在終端機輸入下面這行，然後按 Enter：

```bash
node -v
```

如果看到類似這樣的輸出，表示 Node.js 裝好了：

```text
v24.22.0
```

數字不用完全一樣，只要是 `v24.15` 或更新的版本就可以。

再輸入這行確認 npm 也在：

```bash
npm -v
```

會印出一個版本號，例如 `11.9.0`。

如果出現「找不到指令」之類的錯誤，先把 VS Code 整個關掉再重開；安裝 Node.js 之後，已經開著的程式有時候找不到它。

### 要注意終端機所在的位置

終端機永遠「站在」某個資料夾裡，下的指令都是針對那個資料夾。VS Code 內建的終端機會自動站在你開啟的資料夾，也就是 `learning-vue`。之後執行程式時，如果出現「找不到檔案」，先確認終端機是不是站在正確的資料夾。

## 重點整理

- 執行 JavaScript 要用 Node.js，寫程式碼用 VS Code。
- 安裝 Node.js 的 LTS 版本，npm 會一起裝好。
- 建立 `learning-vue` 資料夾，用 VS Code 開啟它，練習檔案都放在這裡。
- 「檢視」→「終端機」可以打開終端機，`node -v` 可以確認安裝成功。
