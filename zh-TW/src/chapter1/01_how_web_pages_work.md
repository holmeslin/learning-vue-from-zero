# 網頁是怎麼組成的

## 本集目標

知道一個網頁是由哪三種東西組成的，以及 Vue 和 JavaScript 是什麼關係。

## 正文

你每天打開的網頁，不管是新聞、購物網站還是社群平台，拆開來看都只有三種東西：

- **HTML**：決定網頁上「有什麼」。標題、段落、圖片、按鈕，都是用 HTML 寫出來的。
- **CSS**：決定這些東西「長什麼樣子」。顏色、大小、位置、字型，都是 CSS 管的。
- **JavaScript**：決定網頁「會做什麼」。你按下按鈕後跳出視窗、輸入文字時即時顯示搜尋結果，這些行為都是 JavaScript 寫的。

用蓋房子來比喻：HTML 是房子的結構，CSS 是裝潢，JavaScript 是水電和電器。沒有 JavaScript 的網頁也能看，但它就只是一張不會動的海報。

瀏覽器（browser）就是負責讀這三種東西、把畫面畫出來的程式。Chrome、Safari、Edge 都是瀏覽器。

### 那 Vue 是什麼？

Vue 的念法和英文的 view（檢視）一樣。它是用 JavaScript 寫成的框架（framework）。框架的意思是「別人寫好、你拿來用的一堆程式碼，而且幫你定好了程式該怎麼組織」。

現代的網頁，畫面會一直隨著資料變化：新訊息進來、商品加進購物車、按個讚數字就加一。要用純 JavaScript 處理這些變化，程式很快就會亂成一團。Vue 的工作就是幫你管好「資料變了，畫面要跟著變」這件事，讓你只要描述「資料長這樣的時候，畫面該長怎樣」，剩下的交給它。

所以學 Vue 的順序是：

1. 先會 JavaScript，因為 Vue 的程式邏輯全部是 JavaScript。
2. 再會一點 HTML 和 CSS，因為最後畫出來的還是網頁。
3. 然後才是 Vue 本身。

這一章和下一章先專心學 JavaScript。

### JavaScript 不一定要在瀏覽器裡跑

JavaScript 原本是給瀏覽器用的語言，但有一個叫 **Node.js** 的程式，可以讓 JavaScript 離開瀏覽器，直接在你的電腦上執行。

前兩章的程式都會用 Node.js 執行，原因很簡單：這樣你可以只專心在語言本身，不用同時煩惱網頁的事。等語言熟了，再把它接到網頁上。

下一集就來安裝 Node.js。

## 重點整理

- 網頁由三種東西組成：HTML 管內容，CSS 管外觀，JavaScript 管行為。
- Vue 是用 JavaScript 寫的框架，專門處理「資料變了，畫面跟著變」。
- 學 Vue 之前要先會 JavaScript。
- Node.js 讓 JavaScript 不用瀏覽器也能執行，前兩章都用它。
