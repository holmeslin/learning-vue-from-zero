# 第一個程式

## 本集目標

寫出第一個 JavaScript 程式，用 Node.js 執行它，並且看懂執行結果。

## 正文

### 建立檔案

在 VS Code 左邊的檔案清單，把滑鼠移到 `learning-vue` 上，點「新增檔案」的圖示，取名 `hello.js`。`.js` 是 JavaScript 檔案的副檔名，一定要加。

在檔案裡打這一行，然後存檔（Windows 按 Ctrl+S，Mac 按 ⌘S）：

```js
console.log("哈囉，世界！");
```

### 執行

在終端機輸入：

```bash
node hello.js
```

按 Enter，終端機會印出：

```text
哈囉，世界！
```

恭喜，你的第一個程式跑起來了。

`node hello.js` 的意思是「用 Node.js 執行 `hello.js` 這個檔案」。之後每一集的範例都是這樣執行的：存成 `.js` 檔，然後 `node 檔名`。

### 這行程式在做什麼

```js
console.log("哈囉，世界！");
```

拆開來看：

- `console.log` 是「把東西印到終端機上」的指令。之後你會一直用它來看程式裡發生了什麼事。
- 後面的小括號 `()` 裡放要印的東西。
- `"哈囉，世界！"` 是一段文字。程式裡的文字要用引號包起來，這種東西叫**字串**（string），第 7 集會詳細講。
- 最後的分號 `;` 表示「這一句結束了」。JavaScript 其實不加分號也能跑，但這本書一律會加，比較不容易出錯。

### 多印幾行

程式是從上到下一行一行執行的。把檔案改成：

```js
console.log("第一行");
console.log("第二行");
console.log("第三行");
```

再執行一次 `node hello.js`：

```text
第一行
第二行
第三行
```

### 出錯了怎麼辦

故意把引號拿掉試試看：

```js,ignore
console.log(哈囉);
```

執行後會看到一大段紅字，其中有一行是這樣：

```text
ReferenceError: 哈囉 is not defined
```

意思是「`哈囉` 這個東西沒有定義過」。因為沒有引號，Node.js 不把它當成文字，而是去找一個叫 `哈囉` 的東西，當然找不到。

寫程式一定會遇到錯誤，這很正常。遇到錯誤時，先找到 `Error` 那一行讀一讀，大多數時候它會直接告訴你問題在哪。

## 重點整理

- 程式碼存成 `.js` 檔，用 `node 檔名` 執行。
- `console.log()` 把括號裡的東西印到終端機上。
- 文字要用引號包起來。
- 程式從上到下一行一行執行。
- 出錯時找 `Error` 那一行，它通常會說明問題。
