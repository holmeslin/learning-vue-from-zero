# 三元運算子

## 本集目標

用一行寫出「條件成立就是 A，不然就是 B」。

## 正文

### 一個常見的情況

想依照條件決定一個變數的值，用 `if` 會這樣寫：

```js
const age = 20;
let status;

if (age >= 18) {
  status = "成年";
} else {
  status = "未成年";
}

console.log(status);
```

```text
成年
```

能用，但有點囉嗦。而且 `status` 被迫用 `let`，因為它是先宣告、後面才放值進去。

### 三元運算子

同樣的事可以寫成一行：

```js
const age = 20;
const status = age >= 18 ? "成年" : "未成年";
console.log(status);
```

```text
成年
```

拆開來看：`條件 ? 成立時的值 : 不成立時的值`。問號前面是條件，問號和冒號中間是條件成立時得到的值，冒號後面是不成立時得到的值。

這個東西叫**三元運算子**（ternary operator），「三元」是因為它需要三個部分。它是 JavaScript 裡唯一需要三個部分的運算子，所以也常直接叫它「問號冒號」。

好處很明顯：`status` 可以用 `const` 了，而且意圖一目了然。

### 可以直接放進樣板字面值

因為它會算出一個值，所以任何可以放值的地方都能用：

```js
const count = 3;
console.log(`你有 ${count} 則${count > 0 ? "新" : ""}訊息`);
```

```text
你有 3 則新訊息
```

### 什麼時候用

三元運算子適合「二選一、而且兩邊都很短」的情況。如果條件成立時要做好幾件事，或是有三種以上的情況，用 `if` 和 `else if` 比較清楚。

尤其不要把三元運算子疊在一起：

```js,ignore
const level = score >= 90 ? "A" : score >= 80 ? "B" : score >= 70 ? "C" : "D";
```

這行能跑，但讀的人會很痛苦。遇到這種情況，回去用 `if`。

### 預告

三元運算子在 Vue 的模板裡很常見，因為畫面經常是「登入了顯示這個，沒登入顯示那個」這種二選一。第 4 章會看到它。

## 重點整理

- `條件 ? A : B`：條件成立得到 A，不成立得到 B。
- 它會算出一個值，所以可以直接放在 `const` 右邊或樣板字面值裡。
- 只用在二選一、兩邊都很短的情況；不要疊在一起。
