# `if` 與 `else`

## 本集目標

讓程式依照條件決定要做什麼。

## 正文

到目前為止，程式都是從頭執行到尾，每一行都會跑。但真正的程式需要「判斷」：如果怎樣，就做什麼。

### `if`

```js
const age = 20;

if (age >= 18) {
  console.log("可以投票");
}
```

```text
可以投票
```

`if` 後面的小括號放條件，條件是 `true` 就執行大括號 `{}` 裡的程式碼，是 `false` 就整段跳過。把 `age` 改成 16 再跑一次，什麼都不會印。

大括號裡的程式碼習慣往內縮兩格，這樣一眼就看得出哪些行是「在 `if` 裡面」。VS Code 會自動幫你縮排。

### `else`

條件不成立時想做別的事，用 `else`：

```js
const age = 16;

if (age >= 18) {
  console.log("可以投票");
} else {
  console.log("還不能投票");
}
```

```text
還不能投票
```

兩個大括號只會執行其中一個。

### `else if`

超過兩種情況時，中間用 `else if` 接：

```js
const score = 85;

if (score >= 90) {
  console.log("優等");
} else if (score >= 60) {
  console.log("及格");
} else {
  console.log("不及格");
}
```

```text
及格
```

程式會從上往下一個一個檢查條件，碰到第一個成立的就執行那一段，然後**跳過剩下的全部**。`score` 是 85，第一個條件 `85 >= 90` 不成立，第二個 `85 >= 60` 成立，印出「及格」，最後的 `else` 就不看了。

所以順序很重要。如果把 `score >= 60` 放在最前面，90 分以上的人也只會得到「及格」。

### 條件裡直接放布林值

條件只要是布林值就行，不一定要寫比較：

```js
const isLoggedIn = true;

if (isLoggedIn) {
  console.log("歡迎回來");
}
```

`if (isLoggedIn)` 讀起來就像中文的「如果已登入」，比 `if (isLoggedIn === true)` 自然，兩者效果一樣。

## 重點整理

- `if (條件) { ... }`：條件成立才執行大括號裡的程式碼。
- `else { ... }`：條件不成立時執行。
- `else if (條件) { ... }`：接更多情況，由上往下檢查，碰到第一個成立的就停。
- 條件的位置可以直接放布林值變數。
