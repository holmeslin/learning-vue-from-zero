# `const` 與 `let`

## 本集目標

用變數把資料存起來，並且知道什麼時候用 `const`、什麼時候用 `let`。

## 正文

### 把東西存起來

之前我們都是直接把文字寫在 `console.log` 裡。但真正的程式需要把資料「存起來」，之後再拿出來用。存資料的地方叫**變數**（variable）。

```js
const name = "小明";
console.log(name);
```

執行結果：

```text
小明
```

第一行的意思是：建立一個叫 `name` 的變數，把 `"小明"` 放進去。第二行把 `name` 裡的東西印出來。

注意 `console.log(name)` 的 `name` 沒有引號。有引號是「印出 name 這三個字母」，沒有引號是「印出 name 這個變數裡面的東西」。

你可以把變數想成貼了標籤的盒子：`name` 是標籤，`"小明"` 是盒子裡的東西。之後要用的時候，叫標籤名字就好。

### 變數名稱的規則

- 用英文字母開頭，後面可以接字母、數字或底線。
- 大小寫不同就是不同的變數，`name` 和 `Name` 是兩個變數。
- 多個單字時，習慣第一個單字小寫、後面每個單字開頭大寫，例如 `userName`、`totalPrice`。這種寫法叫 camelCase（駝峰式），JavaScript 和 Vue 的世界幾乎都用它。
- 名稱要能說明裡面放什麼。`n` 和 `userName` 都合法，但三天後只有後者看得懂。

### `const` 不能換東西

`const` 是 constant（常數）的縮寫，意思是「這個盒子裡的東西放進去就不換了」。試著換換看：

```js,ignore
const name = "小明";
name = "小華";
```

執行會出錯：

```text
TypeError: Assignment to constant variable.
```

意思是「不能對常數重新指定值」。

### `let` 可以換

如果資料需要改變，用 `let`：

```js
let count = 0;
console.log(count);
count = 1;
console.log(count);
```

執行結果：

```text
0
1
```

第三行的 `count = 1` 沒有 `let`，因為 `count` 已經建立過了，這一行只是把盒子裡的東西換掉。`let` 只有在第一次建立變數時才寫。

### 該用哪個？

**預設用 `const`，真的需要改才用 `let`。**

這聽起來有點反直覺，但理由很實際：讀程式的時候看到 `const`，你就知道這個值從頭到尾不會變，可以放心；看到 `let`，才需要特別留意它在哪裡被改掉。寫 Vue 的時候，你會發現絕大多數變數都是 `const`。

### 關於 `var`

看別人的程式碼時，你可能會看到 `var`。它是很舊的寫法，行為有些古怪，現在不建議用。看到的時候知道它大致等於 `let` 就好，自己不要寫。

## 重點整理

- 變數是存資料的盒子，用名稱來取用。
- `const` 建立的變數不能重新指定值，`let` 可以。
- 預設用 `const`，需要改變的時候才用 `let`。
- 變數名稱用 camelCase，而且要能說明裡面放什麼。
- 不要用 `var`。
