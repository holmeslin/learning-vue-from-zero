# 響應式與互動

上一章做出來的畫面，無論你怎麼點、怎麼打字，它都不會變。真正的網頁會回應你：按讚數字加一、輸入文字立刻出現搜尋結果、勾選待辦事項就畫上刪除線。

這一章要學的，就是讓畫面「活」起來。核心是 Vue 的**響應式**（reactivity）：你只管改資料，Vue 會自己找出畫面上用到這份資料的地方，把它更新。第 3 章最後一集說過，這是 Vue 的兩個核心之一，這一章就來把它學會。

學完這一章，你會從「描述畫面長什麼樣子」，進步到「描述畫面如何隨著資料改變」，最後做出一個完整的待辦清單。

這一章是整本書最重要的一章，之後的每一章都建立在它上面。請放慢速度，每一集都動手做。

## 準備環境

這一章繼續使用第 4 章建立的 `hello-vue` 專案。在專案資料夾打開終端機，啟動開發伺服器：

```bash
npm run dev
```

然後用瀏覽器打開終端機印出的網址（通常是 <http://localhost:5173/>），開著不要關。每一集的範例，除非特別說明，都是「把 `src/App.vue` 換成」範例的內容，存檔後看瀏覽器的變化。

有些範例會用 `console.log` 印東西。印出來的結果不在終端機，而在**瀏覽器**的開發者工具裡：按 F12（Mac 按 ⌘⌥I）打開，切到 Console 分頁。

你需要先熟悉第 4 章的內容，特別是模板裡的 `{{ }}`、`v-bind`、props、`v-if` 和 `v-for`。

## 這一章的主題

1. 用 `v-on` 處理點按鈕、送出表單這些操作。
2. 為什麼普通變數改了，畫面卻不會變。
3. 用 `ref`、`reactive` 建立響應式資料，以及 Vue 是怎麼知道資料變了的。
4. 用 `computed` 從現有的資料算出新的資料。
5. 用 `v-model` 把輸入框和資料綁在一起，做出各種表單。
6. 子元件怎麼用 `defineEmits` 通知父元件，以及用 `defineModel` 讓自己的元件也能用 `v-model`。
7. `nextTick`：資料改了之後，畫面什麼時候才真的更新。
8. 綜合練習：待辦清單。
