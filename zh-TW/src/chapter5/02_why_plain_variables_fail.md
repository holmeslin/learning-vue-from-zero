# 為什麼普通變數不行

## 本集目標

親眼看到「改了普通變數，畫面卻不會變」，理解為什麼 Vue 需要響應式資料。

## 正文

### 一個直覺的做法

做一個計數器：按一下按鈕，數字加一。以你目前學到的東西，最自然的寫法是用一個 `let` 變數。把 `src/App.vue` 換成：

```vue
<script setup>
let count = 0;

function handleClick() {
  count = count + 1;
  console.log("count 現在是", count);
}
</script>

<template>
  <p>已點 {{ count }} 次</p>
  <button @click="handleClick">加一</button>
</template>
```

存檔後，打開 Console，然後連續點按鈕三次。

Console 印出：

```text
count 現在是 1
count 現在是 2
count 現在是 3
```

變數的確一直在增加。但是看看網頁：`已點 0 次`，**畫面完全沒有變**。

### 為什麼不行

先想想第一次打開頁面時發生了什麼事：

1. Vue 執行 `<script setup>` 裡的程式，`count` 是 0。
2. Vue 照著 `<template>` 產生畫面，把 `{{ count }}` 換成當時的值 0，放進 DOM。

這個「照著模板產生畫面」的動作叫**渲染**（render）。渲染完，畫面上的 `0` 就只是一段普通的文字，它不會自己回頭去看 `count` 變成多少了。

之後你點按鈕，`count` 變成 1、2、3，可是**沒有人告訴 Vue**。Vue 不會一直盯著你所有的變數看，它不知道 `count` 變了，也就不會重新渲染，畫面就停在 0。

這和第 3 章最後一集手寫 DOM 的情況一模一樣：在那裡，改完 `count` 還要自己寫一行 `countText.textContent = count`，畫面才會變。普通變數在 Vue 裡也是這樣，改了就只是改了，畫面不會跟著動。

### 需要什麼樣的資料

要做出會變動的畫面，需要一種特別的資料，它要做到兩件事：

1. **被讀的時候**，記住「畫面上的哪些地方用到我」。
2. **被改的時候**，通知 Vue：「我變了，用到我的地方請重新渲染」。

有了這種資料，你只要改資料，Vue 就會自己更新畫面，不用再手動改 DOM。這種「資料一變，畫面就跟著反應」的特性，叫做**響應式**（reactivity），這種資料就是**響應式資料**。

Vue 提供的響應式資料，最基本的一種叫 `ref`，下一集就來用它。

## 重點整理

- 改變普通變數，畫面不會更新，因為 Vue 不知道你改了。
- 渲染是 Vue 照著模板產生畫面的動作；渲染完之後，畫面上的值不會自己更新。
- 響應式資料會在被改的時候通知 Vue，讓用到它的畫面重新渲染。
- 要顯示在畫面上、而且會改變的資料，就要用響應式資料。
