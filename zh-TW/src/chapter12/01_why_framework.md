# 為什麼需要框架

## 本集目標

看懂 create-vue 專案和 Nuxt 專案在「瀏覽器收到什麼」上的差別，並且知道框架幫你做了哪些事。

## 正文

### 瀏覽器收到的是什麼

打開你第一部做的任何一個 create-vue 專案，看一下專案根目錄的 `index.html`。重點只有 `<body>` 裡這兩行：

```html
<body>
  <div id="app"></div>
  <script type="module" src="/src/main.ts"></script>
</body>
```

`<div id="app"></div>` 是空的。使用者打開網站時，瀏覽器先拿到這個空殼，再去下載 JavaScript，等 Vue 執行完，才把畫面掛載到 `#app` 裡。第 4 章 `main.js` 裡的 `mount("#app")`（第 10 章起是 `main.ts`），就是在做這件事。

你可以自己驗證：在瀏覽器網址列的最前面加上 `view-source:`，例如 `view-source:http://localhost:5173/`，就能看到伺服器真正送來的 HTML。你會發現畫面上的文字一個字都沒有。

### 空殼會帶來什麼問題

- **使用者會先看到空白**。JavaScript 下載、執行完之前，畫面上什麼都沒有。網路慢或手機比較舊的時候特別明顯。
- **有些工具讀不到內容**。不執行 JavaScript 的工具，例如部分搜尋引擎爬蟲，或是你把網址貼到聊天軟體時產生預覽的程式，看到的就是那個空殼。
- **資料要等很久**。第 6 章你在 `onMounted` 或 `watch` 裡抓資料：先下載 JavaScript、掛載元件、才開始發出請求、資料回來之後才能畫出內容。每一步都排在前一步後面。
- **功能要自己拼起來**。路由要裝 Vue Router 再手寫 `routes`、圖片要自己最佳化、字型要自己處理、分頁標題要自己改，每個選擇都是你的功課。

### 框架做了什麼

**框架**（framework）是一套「已經把常見決定都做好」的工具。Nuxt 在 Vue 之上多做了這幾件事：

- **在伺服器上先渲染**。伺服器先把 Vue 元件算成 HTML 再送出去，瀏覽器一收到就有內容可以看。這叫**伺服器端渲染**（server-side rendering，簡稱 SSR）。
- **用檔案決定網址**。Vue Router 已經裝好，而且不用手寫 `routes` 陣列，`app/pages/` 裡的檔案怎麼放，網址就怎麼長。
- **自動匯入**。元件、`ref`、`computed` 這些東西不用自己寫 `import`。
- **內建伺服器**。第 14 章你會在同一個專案裡寫出自己的 API。
- **官方模組**。圖片、字型、SEO 這些常見需求，都有現成的模組可以裝。

同一個「關於我們」頁面，用 Nuxt 做出來之後，伺服器送出的 HTML 裡會有這一段：

```html
<main><h1>關於我們</h1><p>我們是一間很小的書店。</p></main>
```

文字已經在 HTML 裡了。第 5 集你會親手做出這個頁面，到時候再自己看一次。

### 那 Vue 還在嗎

在。伺服器送來的 HTML 只是「畫好的圖」，按鈕還不能按。瀏覽器拿到 HTML 之後，一樣會下載 Vue 的 JavaScript，接手這份 HTML，把事件和響應式接上去，畫面才真正「活」起來。這個「接手」的步驟叫 **hydration**，字面意思是「補水」：替伺服器送來的「乾」HTML 補上互動能力。第 13 章會詳細講它。

所以你寫的元件，大部分會跑兩次：一次在伺服器上產生 HTML，一次在瀏覽器裡接手。這一章先不用管這件事，照著第一部的寫法寫就好。

### 要付出的代價

用框架也有代價：

- 要用到第二部教的大部分功能，你的網站需要一個會執行 JavaScript 的伺服器（Node.js），不能只把一堆靜態檔案丟上網路就好。第 15 章會講其他的選擇。
- 多了一組新規則要學：哪些程式碼跑在伺服器上、哪些跑在瀏覽器上、兩邊怎麼合作。這就是第 13 章和第 14 章的內容。

這些代價換來的好處，在做內容比較多、需要被搜尋到、或是資料要從伺服器讀的網站時特別值得。如果你只是做一個純粹在瀏覽器裡玩的小工具，create-vue 依然是很好的選擇。

## 重點整理

- create-vue 專案送給瀏覽器的是空的 `<div id="app"></div>`，畫面要等 JavaScript 執行完才出現。
- Nuxt 會先在伺服器上把畫面算成 HTML，瀏覽器一收到就有內容，這叫伺服器端渲染（SSR）。
- 瀏覽器拿到 HTML 之後，Vue 會接手讓畫面能互動，這個步驟叫 hydration。
- Nuxt 幫你決定了路由、自動匯入、伺服器、圖片字型等常見問題。
- 代價是需要伺服器，而且要學「哪段程式跑在哪裡」的新規則。
