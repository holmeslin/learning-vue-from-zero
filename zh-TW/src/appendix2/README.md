# 附錄二

附錄二是第二部的補充，**選讀**。跳過它不會影響你看懂前面任何一章；等你真的要用到的時候再回來翻也可以。

這裡收了三個你學完 Nuxt 之後很可能會碰到的東西：

- **在 Nuxt 裡用 Pinia**：第 8 章學的 store，搬進 Nuxt 要怎麼裝、怎麼用，以及伺服器端渲染時要注意什麼。
- **Nuxt Layers 與模組**：模組幫 Nuxt 加功能，Layers 讓好幾個專案共用同一套設定與元件。
- **VitePress**：Vue 生態系的文件網站產生器，用 Markdown 寫內容，適合做說明文件或部落格。

三篇都用第二部的方式寫：TypeScript、`npm create nuxt@latest` 建立的專案。VitePress 那篇會另外建一個小專案。

準備環境和第 12 章一樣，只要有 Node.js 24 與 npm 就好，每一集開頭會說明要建立什麼專案。
