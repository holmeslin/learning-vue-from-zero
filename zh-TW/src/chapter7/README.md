# 元件進階

到第 6 章為止，你已經會用 props 把資料傳給子元件、用 emit 把事件傳回來、用預設 slot 把一段內容塞進元件，也會用 composable 把邏輯抽出去。這些足夠寫出一個完整的小網頁了。

但元件一多，你會開始遇到這些問題：

- props 的預設值寫起來很囉唆，能不能短一點？
- 我在元件上加了 `class`，它跑到哪裡去了？
- 一張卡片要讓別人塞「標題」和「內容」兩個地方，一個 slot 不夠用。
- 最上層的資料要給第五層的元件用，難道要一層一層傳 props？
- 對話框被父元素的 CSS 切掉了。
- 切換分頁時，使用者剛打的字不見了。
- 某個元件出錯，整頁跟著壞掉。

這一章就是在解決這些問題。每一集介紹一個 Vue 內建的工具：

1. props 解構與預設值
2. 透傳屬性（`$attrs`）
3. 具名 slot
4. 作用域 slot
5. `provide` / `inject`
6. `<Teleport>`
7. `<Transition>`
8. `<KeepAlive>`
9. 非同步元件
10. 錯誤處理（`onErrorCaptured`）

這些集數彼此獨立，可以照順序讀，也可以遇到問題時再回來查。

## 準備環境

這一章的範例都放在你第 4 章建立的 `hello-vue` 專案裡，不用安裝新的套件。啟動開發伺服器：

```bash
npm run dev
```

每一集通常會先建立一兩個 `src/components/` 底下的元件，再把 `src/App.vue` 整個換成書上的程式碼，存檔後看瀏覽器的變化。第 1 集會用到第 6 章建立過的 `src/composables/` 資料夾。

有些範例會用 `console.log` 印東西，或是要你看元件產生的 HTML。按 F12（Mac 按 ⌘⌥I）打開瀏覽器的開發者工具：印出的訊息在 Console 分頁，HTML 在 Elements 分頁（第 3 章在網頁上按右鍵選「檢查」打開的，就是這個分頁）。
