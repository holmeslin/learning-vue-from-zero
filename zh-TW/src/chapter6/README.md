# 監聽與生命週期

第 5 章學完，你的元件已經會「根據狀態算出畫面」：`ref` 一改，畫面就跟著變；需要從別的值算出來的東西，交給 `computed`。

但真實的網頁不只有畫面。你還會需要：

- 使用者輸入的內容一變，就把分頁標題改掉。
- 元件一出現在畫面上，就讓輸入框取得游標，或是開一個每秒更新的計時器。
- 使用者換了一個選項，就去伺服器抓對應的資料。

這些事情都發生在畫面「之外」，`computed` 管不到。這一章要學的工具，就是專門處理這些事的：

- **監聽**（`watch`、`watchEffect`）：某個值變了，就執行一段程式碼。
- **生命週期 Hook**（`onMounted`、`onUnmounted`）：元件出現在畫面上、從畫面上消失的那一刻，執行一段程式碼。
- **`useTemplateRef`**：拿到真正的 DOM 元素，直接操作它。

學會這些之後，你會用它們從網路上抓資料，並處理「載入中」「出錯了」「請求順序錯亂」這些真實會遇到的狀況。最後，你會學到怎麼把這些邏輯打包成 **composable**，讓不同元件重複使用。

## 準備環境

這一章的範例都放在你第 4 章建立的 `hello-vue` 專案裡，不用安裝新的套件。在專案資料夾打開終端機，執行 `npm run dev` 啟動開發伺服器。大部分範例只要把 `src/App.vue` 整個換成書上的程式碼，存檔後瀏覽器就會自動更新。少數範例需要另外建立檔案，書上會寫出完整的檔名。

第 8 集起會用到一個新資料夾 `src/composables/`，到時候再建立就好。

很多範例會用 `console.log` 印出訊息。要看這些訊息，請打開瀏覽器的開發者工具（按 F12，Mac 按 ⌘⌥I），切到「Console」分頁。

第 6 集和第 9 集會連到網路上的公開測試 API `jsonplaceholder.typicode.com` 抓資料，練習時電腦要連得上網路。
